KYTE / DESIGN SYSTEM / 01

A shared language
for the work.

This page records the visual rules to use when designing or building Kyte pages. It is a working reference for the team, not a public landing page.

Internal reference · v1.0

00 / PRINCIPLES

Quiet structure.
Expressive work.

01

Let the work lead

Use generous space and restrained surfaces so imagery, type and ideas have room to speak.

02

One system, two modes

Dark is the expressive default. Use full light mode for work and case-study reading where it improves focus.

03

Lines stay consistent

Use one solid border token per mode. Avoid white borders with opacity; overlaps can make them look uneven.

02 / TYPOGRAPHY

Clear, measured type.

Use the site’s loaded Geist family with a sans-serif fallback. Let the headline scale fluidly and keep supporting copy easy to scan.

03 / SURFACES & LINES

Soft edges.
Solid color.

Layer surfaces by a small, intentional step. Give every divider the same full-opacity shade within its theme.

05 / LAYOUT & MOTION

Room to think.

GUTTER

24–120px

Scale page edges with viewport width. Keep at least 24px on small screens.

SECTION SPACE

64–128px

Use generous vertical rhythm, reducing it on compact screens.

MOTION

200–500ms

Use motion to clarify state or focus. Respect reduced-motion preferences.
