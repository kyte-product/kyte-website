KYTE / DESIGN SYSTEM / 01

A shared language
for the work.

This page records the visual rules to use when designing or building Kyte pages. It is a working reference for the team, not a public landing page.

Internal reference · v1.0

00 / PRINCIPLES

Quiet structure.
Expressive work.

01

Let the work lead

Use generous space and restrained surfaces so imagery, type and ideas have room to speak.

02

One system, two modes

Dark is the expressive default. Use full light mode for work and case-study reading where it improves focus.

03

Lines stay consistent

Use one solid border token per mode. Avoid white borders with opacity; overlaps can make them look uneven.

02 / TYPOGRAPHY

Clear, measured type.

Use the site’s loaded Geist family with a sans-serif fallback. Let the headline scale fluidly and keep supporting copy easy to scan.

05 / LAYOUT & SPACING

Room to think.

Use the same page frame, content width, gutters and gap scale across every route. Section surfaces, LED patterns and horizontal tickers extend to the vertical frame lines; align text and controls to the page gutter.

PAGE FRAME

1920px max

Keep the full site shell centered and prevent the page from growing beyond the working frame.

FULL-BLEED SURFACES

Frame to frame

Extend section backgrounds, LED patterns and ticker lines to the vertical edges of the page frame.

PAGE GUTTER

22–96px

Use clamp(22px, 5vw, 96px) on wider screens and 22px on compact screens to align content within each section.

SECTION SPACE

64–120px

Use clamp(64px, 7vw, 120px) for major vertical transitions, with 64px on compact screens.

GRID GAP

20–36px

Use clamp(20px, 2.25vw, 36px) between cards, project tiles and gallery items.

COMPONENT GAP

12–24px

Use clamp(12px, 1.5vw, 24px) for closely related controls and component details.

K

Use these tokens before adding page-specific spacing. Keep motion between 200–500ms, use it to clarify state, and respect reduced-motion preferences.
